**宇佐见莲子相关板块内容规划**

### 物品
- **星盘**-- 用途：获取当前维度的信息
  -- 获取：合成获取
  -- 机制：处于主世界可以获取当前主世界时间，月相，群系，坐标,
  处于其他维度仅获取维度，坐标，群系信息，地狱无法使用

- **格林尼治的天文望远镜**
  -- 获取：合成获取
  -- 机制：使用打开gui之后将里面放置一张空白星图，根据所在主世界的坐标获取一份现实中的星图,只能晚上进行,处于末地有意外之喜
  -- 主世界只能看见 太阳系和

- **空白星图**
  -- 获取：合成获取
  1张纸+1紫水晶等于1个

- **星图**
  -- 机制：可以放入星象仪进行投影出该行星/恒星的3D动画，需要先用光谱仪分析
  次要玩法，主世界发现的星图可以做饮品“星辉”末地发现的制作终末星辉，发现的星图只显示名称具体得用

-  **星象仪**
   -- 合成获得

-  **光谱仪**
- -- 合成获得
- -- 机制：分析对应恒星/行星的具体特征温度特征寿命编号等
