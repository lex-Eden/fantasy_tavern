**宇佐见莲子相关板块内容规划**

### 物品
- **星盘**-- 用途：获取当前维度的信息
  -- 获取：合成获取
  -- 机制：处于主世界可以获取当前主世界时间，月相，群系，坐标,
  处于其他维度仅获取维度，坐标，群系信息，地狱无法使用

- **格林尼治的天文望远镜**
  -- 获取：合成获取
  -- 机制：使用打开gui之后将里面放置一张空白星图，根据所在主世界的群系，时间，坐标获取一份现实中的星图,只能晚上进行,处于末地有意外之喜

- **空白星图**
  -- 获取：合成获取
  下界之星+8张纸等于128个
  1张纸+1紫水晶等于1个

- **星图**
  -- 机制：主要的没想好呢还
  次要玩法，主世界发现的星图可以做饮品“星辉”末地发现的制作终末星辉
