# 角色设定：青蓝发兽耳少女

> 来源：一张早期 Minecraft 皮肤（64×64 像素级配色），据此提炼出的可复用人物形象。
> 配色与部件均为从渲染图中取样 / 目视还原，非皮肤文件精确取色。

---

## 一、一句话人设

**淡青蓝长发 + 白色兽耳 + 紫色项圈 + 浅蓝连衣裙 + 深蓝斑点过膝袜的少女，整体冷色调、干净通透，气质「外冷内软」。**

---

## 二、外貌特征

### 头部
| 部位 | 描述 | 取色 |
|---|---|---|
| 发色 | 淡青蓝 / 冰蓝，带水感半透明高光，发梢略深 | 主 `#C7EAF2`　亮 `#E6F8FB`　暗 `#9BD5E4` |
| 发型 | 齐刘海 + 两侧及胸长发，蓬松包裹脸颊，后发长过肩 | — |
| 兽耳 | 头顶一对**白色圆润兽耳**（猫/熊系），内耳为淡蓝白 | `#FFFFFF` / `#DCEFF6` |
| 肤色 | 极浅奶油白，无明显妆感 | `#F7E7DC`　阴影 `#E8CDBE` |
| 眼睛 | 薄荷绿大眼，瞳色偏亮，带高光点 | 瞳 `#8FCF7A`　深 `#5FA84F` |
| 腮红 | 淡粉，位置偏低（眼下偏外侧） | `#F3B9B0` |
| 嘴 | 极小的一条弧线 | `#C98A8A` |

### 颈部
- **紫色细项圈**（`#7B4FC9`）——全身最醒目的识别点，也是唯一的暖调/高饱和点缀。
- 脖子裸露，无围巾、无披风。

### 服饰（自下而上分层）
1. **过膝袜靴**：深蓝底 + 亮蓝不规则斑点（像雪花/星点），袜口一圈浅蓝白边，鞋底更深近黑蓝。`#2C3A5C` ＋ `#93BDE4`
2. **裙摆**：两层——外层淡紫 `#CDC0EC`，内层更浅 `#E4DCF6`；**右侧腰际有一块薄荷绿** `#A9E3A2`。
3. **腰部**：白色束带 `#FFFFFF`，把上下身分开。
4. **连衣裙身**：浅天蓝 `#A9C7EA`，中央有一道**靛蓝色竖向拼接** `#4E6BA8`，胸前上方是一块**深藏青胸襟**。
5. **肩部**：左右各一个**深藏青护肩/肩甲** `#3E4E6B`，包裹肩头。
6. **手臂**：完全裸露，无袖、无手套，肤色偏白。

## 三、气质与人物定位建议

- **气质**：清冷、安静、干净；配色冷静但薄荷绿与腮红带来柔和感 → **「外冷内软」**。
- **性格**：话不多，礼貌，有点怕生；对熟悉的人会露出小表情。
- **定位可选**：水系 / 冰系法师、治愈系辅助、学院里的书呆子优等生、雪原或湖畔的住民。
- **动作习惯**：喜欢把两侧长发拢到耳后；紧张时摸项圈。
- **声音 / 氛围**：轻声，背景音是水声或风声。

## 五、还原度说明

- **明确可见**：淡青蓝长发、白色兽耳、薄荷绿眼睛、紫色项圈、浅蓝连衣裙 + 深藏青肩部、深蓝斑点袜靴、裸臂、极浅肤色。
- **合理推测**：项圈为独立饰品而非衣领；裙摆为双层淡紫；腰侧薄荷绿为色块装饰而非口袋；兽耳为真耳而非发饰。
- **未能确认**：背面发型细节、皮肤上的表情变化、是否有披风或背包等第二层附件（早期皮肤通常信息量有限，可按需增补）。

原图渲染分辨率仅约 431×544 且模型处于轻微侧转角度，以上取色为**目视近似值**；若要精确到像素，需要原始的 64×64 皮肤 PNG 文件。
